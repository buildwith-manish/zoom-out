VOICEOVER SCRIPT — Zoom Out: Food Edition
==========================================
US English · upbeat, warm, game-show host energy
Pace: confident and clear, slight pause between lines

Save each clip as the filename shown, in public/voiceover/
Supported formats: .wav .mp3 .m4a .aac .ogg .flac
Run  npm run voiceover  after recording to register clips.

──────────────────────────────────────────────────────────────
  NAMING KEY
  qq##.wav   = question phase  (plays before zoom/timer starts)
  q##.wav    = reveal moment   (plays when answer slams in)
  bonusq#.wav = bonus question (plays at start of bonus scene)
  bonus#.wav  = bonus reveal   (plays when bonus answer hits)
  intro.wav  · outro.wav · sting.wav = named scenes
──────────────────────────────────────────────────────────────

──────────────────────────────────────────────────────────────
  RECORDING NOTES

  Tone:
  · Warm, upbeat game-show host — think Food Network meets trivia night.
  · Question clips (qq##): curious, slightly teasing — let the silence
    after the line work. Don't rush.
  · Reveal clips (q##): punchy, one beat, land it like a buzzer hit.
  · Bonus question clips (bonusq#): a notch more excited — this is the
    special round.
  · Bonus reveal clips (bonus#): answer + one short reaction line, done.
  · Intro: hook the viewer in the first two seconds.
  · Outro: conversational, like you're talking directly to one person.

  Pacing:
  · qq## clips: aim for 2.5–4 seconds total. The zoom starts after the
    clip ends, so if you go long the scene stretches to fit — don't worry.
  · q## clips: 1–2 seconds. Short and sharp.
  · bonusq# clips: 4–6 seconds. Viewers need a moment to process.
  · bonus# clips: 2–4 seconds.
  · intro.wav: 6–9 seconds.
  · outro.wav: 5–8 seconds.

  After recording all clips, run:
    npm run voiceover
  to register them and get a coverage report.
